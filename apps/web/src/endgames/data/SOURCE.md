# Endgame family texts (`familyTexts.ts`)

The short endgame descriptions in `familyTexts.ts` (M32-4, ADR-025 section 5) were written for
DaisyChess in our own words and are GPL-3.0-or-later like the rest of `apps/web`. No text is
copied or adapted from Wikipedia, lichess, chess.com, books or any other source. The keys are the
`EndgameFamily` values of `@daisychess/endgames` (one entry per family, including `other`).


## Lessons (`lessons.ts`)

The 16 lessons of the endgame trainer (ADR-025 §6) were authored for DaisyChess. The start
positions are classic theoretical endgames set up by hand; the titles, texts and hints are written
in our own words and are GPL-3.0-or-later like the rest of `apps/web`. No text is copied or adapted
from books, Wikipedia, lichess, chess.com or any other source.

## Verdicts (`lessons.verdicts.json`)

Generated by `packages/endgames/scripts/verify-lessons.mjs`, which asks the lichess tablebase API
(`https://tablebase.lichess.ovh/standard?fen=…`, derived from Syzygy tables; lichess publishes the
API and its data openly, the facts about a position are not copyrightable) once per start position
and records `category`, `dtm`, `dtz`, the number of legal moves and the number of moves that keep
the lesson's result (`keepers`). `dtm` and `dtz` are in plies, from the point of view of the side to
move (the user).

- Fetched: 2026-11-06.
- A win lesson's budget must be at least ceil(dtm / 2) + 4 user moves; the script and
  `lessons.test.ts` both check it.

Regenerate after editing a start position or a budget (network needed; never run in CI):

    pnpm --filter @daisychess/endgames build
    node packages/endgames/scripts/verify-lessons.mjs

The script needs Node 22.18+ or 24 (it loads `lessons.ts` with built-in type stripping). Use
`--check` to verify without writing.

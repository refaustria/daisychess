Contribute

Bug reports, ideas, translations, fixes and new features are welcome.

  • Read CONTRIBUTING.md for the development setup (Node 20+, pnpm) and conventions.
  • Open an issue for bugs and feature requests.
  • Please follow the code of conduct.
  • Found a security problem? Please report it privately — see Support.

Run your own

The web app works on its own with the browser engine. For server analysis, rooms and the review store, run the engine server next to it — one Docker command:

git clone {{REPO_URL}} && cd daisychess
docker compose -f docker/docker-compose.yml up --build -d
# web app + engine server on http://localhost:8080

A single host with nginx and systemd, and the community hub, are described in the repository's deployment guide. Want to help the hosted service instead? Run a community node.

At a glance

  • No tracking, no advertising, no analytics and no third-party SDKs that collect data.
  • No account, no name, no e-mail, no location, no contacts, no device identifiers.
  • Settings, tokens, trainer progress and the review cache stay on the device.
  • All traffic is encrypted (HTTPS and secure WebSockets).
  • Deletion: daisychess.org/delete-data/

App Store (App Privacy)

Tracking
No, the app does not track users.
Data Linked to You
None.
Data Not Linked to You
User Content → Other User Content (game reviews in the shared review store) — purpose: App Functionality.
Usage Data → Other Usage Data (daily search counters per token, only with a node or pool token) — purpose: App Functionality. [OWNER: check]
Not collected
Contact info, health, financial info, location, sensitive info, contacts, browsing and search history, identifiers, purchases, diagnostics.
Notes
Positions sent for live analysis are processed in real time and not retained, so they are not “collected” in Apple's sense. The app uses only HTTPS, so it qualifies for the standard encryption exemption (no proprietary cryptography).

Google Play (Data safety)

Collects or shares data
Yes.
Collected
App activity → Other user-generated content: game reviews (optional, not linked to a user, App functionality).
App activity → App interactions: daily search counters per token (optional, App functionality). [OWNER: check]
Chess positions for analysis: processed ephemerally.
Shared
App activity → Other user-generated content: chess positions go to the operator of a community node when you analyse there (App functionality). This is a user-chosen transfer with a notice in the app; declaring it is the transparent choice. [OWNER: check]
Encrypted in transit
Yes.
Deletion
Users can request deletion — daisychess.org/delete-data/. The app has no user accounts.
Target audience
Not directed at children.
